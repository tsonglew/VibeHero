# Project Instructions

- All user-facing UI text must go through the app i18n layer in `Sources/VibeHero/Localization.swift`.
- The app currently supports English, Simplified Chinese, and Japanese. Add translations for all three languages when adding or changing role labels, settings labels, menu items, HUD status text, combat text, and empty/error states.
- English is the fallback language. Keep README examples aligned with the English labels unless the section is explicitly about localization.
